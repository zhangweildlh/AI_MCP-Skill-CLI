## 5Why 追问链（标准版）

> 从具体观察出发，逐层追问 why，最多 5 次

### 观察起点

- **具体观察**：[必须是可验证的事实，非解读/推测]
- **观察来源**：[日志/用户反馈/监控数据/代码审查等]

### 追问链

| 层级 | 追问 | 回答 | 备注 |
|------|------|------|------|
| 1st why | 为什么会 [观察]？ | [直接原因] |      |
| 2nd why | 为什么会 [直接原因]？ | [更深层原因] |      |
| 3rd why | 为什么会 [更深层原因]？ | [根因候选] |      |
| 4th why | 为什么会 [根因候选]？ | [确认的根因] |      |
| 5th why | 为什么会 [确认的根因]？ | [不可再分的根本原因] |      |

> 若提前抵达根因，剩余层级留空并标注终止原因

### 终止原因

- [ ] 根因达到（在第 X 层）
- [ ] 死胡同回退（回退到第 X 层，改问其他角度）
- [ ] 复杂系统标注（涉及人/组织/文化等多因果，标注为「待验证假设」）

### 根因陈述

- **根因**：[明确的根因陈述，而非症状描述]
- **置信度**：[高 / 中 / 低]
- **支撑证据**：[列出关键证据]
