# structure_audit.py 报告结构说明（参考资料）

> 本文件为参考资料，供 Skill 调用者理解 `structure_audit.py` 的输出结构。**Skill 运行时并不依赖本文件**。
> 注意：L3 语义区段（第 11 节）仅做**报告**，**不写回**原文档。

## 一、报告十节结构

报告按以下十节顺序组织：

1. **概览**：文档基本信息、总章节数、违规计数汇总、整体结论（PASS/FAIL）。
2. **L1 禁用词**：检出第 9 条具名禁用词（见 `banned_terms.txt`）的命中位置与原文片段。
3. **L2 结构**：标题层级（第 2 条）、有序列表序号连续性（第 4 条）、围栏代码块语言标注（第 5 条）等结构性检查。
4. **引用有向图与方向性**：构建章节间引用关系，标注每条边的方向语义（见下文五类边）。
5. **循环引用**：检出引用环（如 A→B→A），列出环路路径。
6. **索引两列 + 盲点**：索引表的两列（编号/标题列、页码/锚点列）精确性与唯一性校验；盲点指正文存在但索引遗漏的条目。
7. **导航可达性**：从文档入口出发，所有章节是否可达，列出不可达节点。
8. **六连验证**：六项机器校验的 PASS/FAIL 与证据分母（见下文）。
9. **四性结论**：精准性、唯一性、一致性、可达性的判定口径与结果（见下文）。
10. **L3 语义待人工确认**：机器无法判定的语义层问题（如表述歧义、逻辑矛盾），仅列示，需人工确认。
11. **整改建议**：按优先级给出可落地修改建议。

## 二、六连验证六项

每项均给出 `PASS` 或 `FAIL`，并附**证据分母**（即该项参与判定的样本总数，用于说明结论如何得出）。约定如下：

| 项 | 含义 | 证据分母 |
|----|------|----------|
| 章号连续性 | 章节编号是否连续无缺漏跳号 | 期望章节总数 N |
| 索引两列精确唯一 | 索引两列是否精确且值唯一 | 索引条目总数 M |
| 裸编号残留 | 是否存在未配对/游离的裸编号 | 扫描到的编号总数 K |
| 围栏配对数 | 围栏代码块 ``` 是否成对闭合 | 围栏起始标记数 P |
| 导航可达性 | 从入口出发所有章节是否可达 | 章节节点总数 Q |
| 节级引用精确命中 | 节级交叉引用是否精确命中目标 | 引用总数 R |

输出形如：`章号连续性: PASS (N=12)`、`索引两列精确唯一: FAIL (M=40, 命中 38)`。

## 三、四性结论四项判定口径

- **精准性**：引用/索引指向的目标存在且精确（不指向错误或多目标）。任意必要引用缺失或指向错误即判 FAIL。
- **唯一性**：索引条目、章节编号、锚点 ID 全局唯一，无重复值。出现重复即判 FAIL。
- **一致性**：标题层级、列表序号、代码块语言标注等符合「12 条强制要求」，且与正文表述一致。
- **可达性**：从文档入口可导航到达全部章节（无孤立/不可达节点）。存在不可达节点即判 FAIL。

## 四、引用方向五类边

有向图中每条边按语义归为以下五类之一：

- **IDX**：指向索引表条目（index）的边。
- **SAME**：指向同一文档内、同一父章节下的边（同级互引）。
- **BACK**：向后引用（指向编号更小的章节，如第 §3 引用 §1）。
- **FWD**：向前引用（指向编号更大的章节，如第 §1 引用 §3）。
- **DANGLING**：悬空引用（目标不存在或无法解析）的边。

## 五、JSON 输出模式

当以 JSON 模式输出时，顶层键名与嵌套层级约定如下：

```
{
  "overview": { ... },          // 第1节 概览
  "l1_banned_terms": [ ... ],   // 第2节 禁用词命中列表
  "l2_structure": { ... },      // 第3节 结构检查
  "reference_graph": {          // 第4节 有向图
    "nodes": [ ... ],
    "edges": [                  // 五类边: IDX/SAME/BACK/FWD/DANGLING
      { "from": "...", "to": "...", "type": "FWD" }
    ]
  },
  "cycles": [ ... ],            // 第5节 循环引用
  "index_table": {              // 第6节 索引两列+盲点
    "two_columns": [ ... ],
    "blind_spots": [ ... ]
  },
  "navigation": {               // 第7节 导航可达性
    "reachable": [ ... ],
    "unreachable": [ ... ]
  },
  "six_validations": {          // 第8节 六连验证
    "chapter_continuity": { "result": "PASS", "denominator": 12 },
    "index_unique": { "result": "FAIL", "denominator": 40 },
    "bare_numbers": { ... },
    "fence_pairs": { ... },
    "navigation_reachable": { ... },
    "section_reference_hit": { ... }
  },
  "four_qualities": {           // 第9节 四性结论
    "precision": "PASS",
    "uniqueness": "PASS",
    "consistency": "FAIL",
    "reachability": "PASS"
  },
  "l3_semantic_pending": [ ... ], // 第10节 待人工确认（仅报告不写回）
  "suggestions": [ ... ]          // 第11节 整改建议
}
```

> 说明：顶层为单一对象，各节以独立顶层键呈现；图结构与六连验证/四性结论内部再按语义嵌套子对象或数组。
