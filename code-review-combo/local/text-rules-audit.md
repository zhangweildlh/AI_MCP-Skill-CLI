# 本地增强：文本规则 / 纪律质量镜

> 同属 code-review-combo 本地质量镜，判据为 combo 自有定义。面向规则集、纪律条款、规范文本。
> 发现以 category: other 进入既有 findings[]；不改 merge_reports / JSON Schema / 三路流水线 / 单一写者契约。
> 与 Skill 结构镜（skill-audit-dimensions.md）叠加使用：Skill 审计同时套用结构镜 + 本镜。

## 严重度口径（combo 语义为唯一权威）

- `high`：规则自相矛盾致执行分叉，或含明文凭证（后者升 `security` / `critical`）。
- `medium`：歧义 / 边界缺失 / 证据不足。
- `low`：组织与表述优化。
- `⊘`：非规则类文本不适用，**不是严重度**。
- `critical`：专留给运行时后果；文本缺陷默认不占，除非直接致运行时危害（如明文密钥）。

## 维度清单（TR-1 ~ TR-6）

- **TR-1 规则自洽**（适用规则 / 纪律文本）：条款间有无矛盾、职责重叠、一词多义 / 多词一义 → `high`。
- **TR-2 可执行性**（适用规则 / 纪律文本）：条件能否用是 / 否或数值判定，有无「酌情 / 适当 / 必要时」等模糊词 → `medium`。
- **TR-3 边界与异常**（适用规则 / 纪律文本）：入参非法 / 结果为空 / 超范围 / 失败兜底是否覆盖 → `medium`。
- **TR-4 单一事实源**（适用规则 / 纪律文本）：同一规则是否在多处重复定义（易漂移） → `medium`。
- **TR-5 反过度声称**（适用规则 / 纪律文本）：完成态措辞是否有可核验依据；计划中 / 元数据兜底 / 待评审 / 本地命令是否被当作已达成事实 → `high`。
- **TR-6 证据可核验**（适用规则 / 纪律文本）：关键结论是否锚定行号 / 命令 / 产物，是否可复现 → `medium`。

## 形态适用性

- 非规则类文本（如纯故事、纯数据、纯样例）→ 全部 TR 维度标 `⊘`，**不计入问题、不计入严重度分布**。
- 判定在覆盖笔记留痕。

## 与严重度来源信号的对应（思想参考，非内联）

输入信号（致命 / 严重 / 一般 / 不适用）仅作分类参考。**严重度映射的唯一权威在 `SKILL.md` 核心原则段「Skill 与文本质量镜」**，本镜不重复映射表，避免多处定义漂移。本文件「严重度口径」章节仅界定各级别的判定含义。
