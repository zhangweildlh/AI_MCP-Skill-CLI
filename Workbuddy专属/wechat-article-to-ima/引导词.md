# 引导词（调用范式）

> 本文件是 `wechat-article-to-ima` 四套调用范式的**唯一权威**：引导词 A / B / C（卡片全量采集，从头强制全量重搜）+ 续跑守护（断点续跑）。每套**单段自含、可独立复制粘贴给任一已加载本技能的调度方直接闭环执行**，不引用、不内联其他引导词。
>
> **唯一事实源分工**：采集工作流 12 步、过滤规则、完整性闸门、抓取降级链、入库流程、状态机（F9）、收尾清扫、任务卡配置表、任务卡轮转规则 —— 一律以 `SKILL.md` 为唯一事实源，代码实装见 `scripts/`。本文件只声明「对哪张卡、什么模式、本卡参数、调度方须手工落地的动作、关键命令、闭环判据」，**不复述 `SKILL.md` 与代码已有的流程、规则、步骤**。
>
> **路径约定（四套通用）**：
> - `[WS]` = 工区绝对路径 `D:\Documents\AI_Work_Temp\ima+WorkBuddy`；
> - `[SKILL]` = 本次加载的 `wechat-article-to-ima` 技能目录绝对路径（`check-deps.js` 输出的技能基址 + `/wechat-article-to-ima`）；
> - `[FID]` = `state.js resolve-folder --name "<该卡 folder_name>" --kb-id ima_kb_QFSIbCma` 实时解析所得 `folder_id`；
> - 下列命令一律用绝对路径，**不依赖当前工作目录**；**禁止硬编码 `folder_id`**（folder 被重建/改名即失效，为历史 D-1 缺陷根因）。
>
> **闭环通则（四套同构）**：`status=completed` 仅在下方闭环判据**全部满足**时写入；任一未满足即按「未达闭环判据即视为断点」写 `partial` 并如实披露，**禁止伪造 completed**。注意 `state.js report` 四栏齐全 ≠ 闭环：还有第 5 栏「移交Agent编排」与「闭环判定」行，且 `pending_fetch/` 与 `failed_quarantine/` 的残留不由 report 统计，须另核。

  - 任一未满足：`node "[SKILL]/scripts/state.js" --progress "[WS]/_progress_A.json" update-card --card A --last-run <今天> --next-due <今天+10天> --status partial --failure-class transient --pending-keywords "<未搜词>" --note "<断点说明>"`；反爬熔断（F4a）时改 `--status antispider_partial` 并加 `--next-retry-at <下次重试时刻>`。

  任一不满足即为断点，写 `partial` 并披露。

## 引导词 续跑守护 —— 对 A/B/C 断点续跑

**断点续跑定义**：某一卡片词簇未全部搜索；某关键词命中文章未全部下载；某文章未完整下载为本地 MD；本地 MD 未真实入库 ima；运行中被限流熔断 / 网络或凭据异常中断等，导致该卡未达闭环判据。

调用 `wechat-article-to-ima` 续跑守护，**逐卡串行**（A → B → C，不并行）核查与续跑。

- **路径与知识库**：`[WS]=D:\Documents\AI_Work_Temp\ima+WorkBuddy`；`[SKILL]` = 本次加载的 `wechat-article-to-ima` 技能目录绝对路径（`check-deps.js` 输出的技能基址 + `/wechat-article-to-ima`）；`knowledge_base_id=ima_kb_QFSIbCma`；`[FID]` 由 `resolve-folder --name "<该卡 folder_name>"` 实时解析（三卡 folder_name 取自 `SKILL.md` 任务卡配置表，**禁止硬编码**）。所有命令用绝对路径，不依赖当前工作目录。
- **每卡执行**（全程必带 `--card <卡>`）：
  1. 读 `_progress_<卡>.json`：`failureClass=permanent`（`interrupted`）→ **停止续跑并提示人工处理凭据**；`partial` / `pending` / `antispider_partial` / `limited` → 进入续跑。**不调用 `reset-card`**（续跑须保留 `searchedKeywords` 用于差集）。
  2. 取 `[FID]`：`node "[SKILL]/scripts/state.js" resolve-folder --name "<该卡 folder_name>" --kb-id ima_kb_QFSIbCma --json`。
  3. 取未搜词差集：`node "[SKILL]/scripts/state.js" --progress "[WS]/_progress_<卡>.json" diff-keywords --card <卡> --keywords "<该卡全量关键词（主+变体，取自 SKILL.md 任务卡配置表）>"`；只搜剩余词（已搜词跳过，避免重触限流），每个结果 JSON 跑 `node "[SKILL]/scripts/pipeline.js" --workspace "[WS]" --card <卡> --search "<x.json>" --kb-id ima_kb_QFSIbCma --folder-id "[FID]"`；每完成一词即 `update-card --searched-keywords "<该关键词>"` 累积。
  4. 回收 2/3 级 handback：`node "[SKILL]/scripts/pipeline.js" --workspace "[WS]" --card <卡> --ingest-pending --kb-id ima_kb_QFSIbCma --folder-id "[FID]"`（消费已去除 `NEEDS_FETCH` 标记的回交物；仍为 stub 者跳过，不合格回交物拒收并保留）。
  5. 回收隔离区残留：`node "[SKILL]/scripts/pipeline.js" --workspace "[WS]" --card <卡> --ingest-quarantine --kb-id ima_kb_QFSIbCma --folder-id "[FID]"`（**严禁不带 `--card`**，否则误食他卡残留）。
  6. 复验：`node "[SKILL]/scripts/state.js" --progress "[WS]/_progress_<卡>.json" report --kb-id ima_kb_QFSIbCma --folder-id "[FID]"`。
  7. 收尾轮转（步骤 12）：
     - 该卡闭环判据全满足：`node "[SKILL]/scripts/state.js" --progress "[WS]/_progress_<卡>.json" update-card --card <卡> --last-run <今天> --next-due <今天+10天> --rotate-index 0 --status completed --note "<本轮结果>"`
     - 任一未满足：`node "[SKILL]/scripts/state.js" --progress "[WS]/_progress_<卡>.json" update-card --card <卡> --last-run <今天> --next-due <今天+10天> --status partial --failure-class transient --pending-keywords "<未搜词>" --note "<断点说明>"`（反爬熔断 F4a 改 `--status antispider_partial` 并加 `--next-retry-at`）。
- **每卡闭环判据**：`report` 四栏齐全且「移交Agent编排 = 0」、闭环判定行显示无待办、无幽灵记录；`pending_fetch/` 本卡 stub 残留为 0；`failed_quarantine/` 中该卡 `<卡>__` 前缀残留清零（仅 `failureClass=permanent` 交人工）；两词簇均已检索。三卡全部满足才算守护闭环。
- **失败分类**（纯离线，无需 `--progress` / `--card`）：`node "[SKILL]/scripts/state.js" classify-failure --reason "<失败原因>"` 判定 `transient` / `permanent`，供调度方决策。
