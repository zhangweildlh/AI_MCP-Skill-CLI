> 四套调用范式：A / B / C（卡片全量采集，从头强制全量重搜）+ 续跑守护（断点续跑）。**每套章节自含全部调用契约**：只复制该套章节正文，粘贴给任一已加载 `wechat-article-to-ima` 的 Agent / WorkBuddy，零编辑即可执行；各套之间不互相引用，也不依赖本文件其他段落。

- **路径与符号（本段自含，禁止跨段取值）**：

  - `[SKILL]` = 调度方加载本技能时取得的 `wechat-article-to-ima` 技能目录绝对路径（即 `SKILL.md` 所在目录）；`check-deps.js` 仅为依赖自检入口，**不作为 `[SKILL]` 的来源**；
  - `[FID]` = 本段 `resolve-folder` 命令对 `工程总承包EPC` 实时解析所得 `folder_id`；
  - 下列命令一律用绝对路径，**不依赖当前工作目录**；**禁止硬编码 `folder_id`**（folder 被重建/改名即失效）。
- **本卡参数**：`card=A`；`knowledge_base_id=ima_kb_QFSIbCma`；`folder_name=工程总承包EPC`；关键词簇 = 主词簇（工程总承包、EPC、总包）+ 变体词簇（总承包EPC、EPC总承包），两簇逐一全搜。
- **执行前唯一前置动作**：`node "[SKILL]/scripts/state.js" --progress "[WS]/_progress_A.json" reset-card --card A`（全量重搜唯一入口；续跑禁用）。
- **执行指针**：按 `SKILL.md`「工作流」端到端执行；所有 `pipeline.js` / `state.js` 写操作必带 `--card A`。依赖自检入口：`node "[SKILL]/scripts/check-deps.js"`。
- **调度方须手工落地的动作（代码不自动做）**：每完成一个关键词检索即 `node "[SKILL]/scripts/state.js" --progress "[WS]/_progress_A.json" update-card --card A --searched-keywords "<该关键词>"`。
- **关键命令**（`[FID]` 取本段 `resolve-folder` 返回值）：
  - 解析目标子目录：`node "[SKILL]/scripts/state.js" resolve-folder --name "工程总承包EPC" --kb-id ima_kb_QFSIbCma --json`
  - 复验：`node "[SKILL]/scripts/state.js" --progress "[WS]/_progress_A.json" report --kb-id ima_kb_QFSIbCma --folder-id "[FID]"`
  - 收尾前回收 2/3 级 handback：`node "[SKILL]/scripts/pipeline.js" --workspace "[WS]" --card A --ingest-pending --kb-id ima_kb_QFSIbCma --folder-id "[FID]"`
  - 收尾前回收隔离区残留：`node "[SKILL]/scripts/pipeline.js" --workspace "[WS]" --card A --ingest-quarantine --kb-id ima_kb_QFSIbCma --folder-id "[FID]"`（**严禁不带 `--card`**）
- **闭环通则（本段自含）**：`status=completed` 仅在本段闭环判据**全部满足**时写入；任一未满足即按「未达闭环判据即视为断点」写 `partial` 并如实披露，**禁止伪造 completed**。注意 `state.js report` 四栏齐全 ≠ 闭环：还有第 5 栏「移交Agent编排」与「闭环判定」行，且 `pending_fetch/` 与 `failed_quarantine/` 的残留不由 report 统计，须另核。
- **收尾轮转（唯一写入口，二选一）**：
  - 闭环判据全满足：`node "[SKILL]/scripts/state.js" --progress "[WS]/_progress_A.json" update-card --card A --last-run <今天> --next-due <今天+10天> --rotate-index 0 --status completed --note "<本轮要点>"`
  - 任一未满足：`node "[SKILL]/scripts/state.js" --progress "[WS]/_progress_A.json" update-card --card A --last-run <今天> --next-due <今天+10天> --status partial --failure-class transient --pending-keywords "<未搜词>" --note "<断点说明>"`；反爬熔断（F4a）时改 `--status antispider_partial` 并加 `--next-retry-at <下次重试时刻>`。
- **闭环判据（全部满足才可判 completed）**：
  1. `report` 四栏齐全，且「移交Agent编排 = 0」、闭环判定行显示无待办、无幽灵记录；
  2. `pending_fetch/` 中本卡 stub 残留为 0；
  3. `failed_quarantine/` 中 `A__` 前缀残留清零（仅 `failureClass=permanent` 的条目交人工）；
  4. 两词簇均已检索（被反爬阻断的词须写入 `pendingKeywords`，此时视为未达全量）。
  任一不满足即为断点，写 `partial` 并披露。
