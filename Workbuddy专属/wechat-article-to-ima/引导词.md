# 引导词（调用范式）

> 本文件沉淀 `wechat-article-to-ima` 的四套调用范式：**引导词 A / B / C（卡片全量采集）+ 续跑守护（断点续跑）**。每套均为**单段、可独立复制粘贴给任一已加载本技能的 Agent 直接闭环执行**；具体的检索→过滤→闸门→入库→状态回写→复验→收尾工作流、命令与卡片参数（`folder_id`、全量关键词簇）一律以技能 `SKILL.md`（含「任务卡配置表」「采集工作流」「断点续跑与续跑守护」）为唯一事实源，本文件**不复现**这些步骤，避免双源漂移。
> 架构约束（零 Agent 表述）：本文件只声明「对哪些卡片、什么模式、是否并行」，不指派执行主体；执行拓扑由调度方经引导词传入。通用闭环判据（三卡同构）：目标卡 `status=completed`、复验四栏齐全、`failed_quarantine/` 中该卡前缀残留清零（仅余 `permanent` 残留交人工）。

## 引导词 A —— 卡片 A（总包）全量采集（首跑 / 周期全搜）

调用 `wechat-article-to-ima` 对**卡片 A（总包）**执行全量采集（首跑或周期全搜）：按技能 SKILL.md「采集工作流」端到端执行并闭环，全程必带 `--card A`；卡片 A 的 `folder_id` 与全量关键词簇取自 SKILL.md「任务卡配置表」，进度文件为 `[WS]/_progress_A.json`（每卡隔离、文件锁+原子写）。闭环判据：本卡 `status=completed`、复验四栏齐全、`failed_quarantine/` 中 `A__` 前缀残留清零（仅余 `permanent` 交人工）。

## 引导词 B —— 卡片 B（城更）全量采集（首跑 / 周期全搜）

调用 `wechat-article-to-ima` 对**卡片 B（城更）**执行全量采集（首跑或周期全搜）：工作流同 A，仅 `--card B` 与 B 卡 `folder_id`、全量关键词簇取自 SKILL.md「任务卡配置表」，进度文件 `[WS]/_progress_B.json`；闭环判据同 A（唯卡片为 B）。**重跑差异**：需「从头强制全量重搜」时先 `reset-card --card B`（仅清 B、不动 A/C）再走工作流；普通周期续跑**不要** reset，保留 `searchedKeywords` 由续跑守护经 `diff-keywords` 取剩余词。

## 引导词 C —— 卡片 C（全域土地）全量采集（首跑 / 周期全搜）

调用 `wechat-article-to-ima` 对**卡片 C（全域土地）**执行全量采集（首跑或周期全搜）：工作流同 A，仅 `--card C` 与 C 卡 `folder_id`、全量关键词簇取自 SKILL.md「任务卡配置表」，进度文件 `[WS]/_progress_C.json`；闭环判据同 A（唯卡片为 C）。**隔离区要点**：`failed_quarantine/` 按卡加前缀，C 卡残留不误入 A/B；补入历史失败残留时 `ingest-quarantine` **必须带 `--card C`**，严禁不带 `--card` 跑（否则误食他卡残留）。

## 引导词 续跑守护 —— 对 A/B/C 断点续跑

调用 `wechat-article-to-ima` 续跑守护：**逐卡（A → B → C）串行**核查与续跑（不并行），目标三卡全部完整执行；每卡按 SKILL.md「断点续跑与续跑守护」节执行——判定续跑信号→`diff-keywords` 取剩余词→补搜补入→消费 `failed_quarantine/<卡>__*.md`→收尾，必带 `--card <卡>`。续跑信号不依赖单一 `status`：须结合 `diff-keywords` 差集与隔离区残差综合判定，`failureClass=permanent` 须停止并转人工。三卡全量关键词簇均取自 SKILL.md「任务卡配置表」。闭环判据：三卡皆 `status=completed`、各自 `failed_quarantine/` 残留清零。
