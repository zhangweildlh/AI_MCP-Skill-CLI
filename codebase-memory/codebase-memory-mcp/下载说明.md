# codebase-memory-mcp 可执行文件获取说明

> 本文件说明 `codebase-memory-mcp` 运行时二进制的获取方式，以及本仓库为何不托管它。

## 为何未纳入仓库

`codebase-memory-mcp.exe` 真实体积约 **282 MB**，已超出 GitHub 单文件 **100 MB** 的硬上限（超过即被远端拒绝推送）。因此本仓库**不托管该二进制**，仅以占位文件标记其应存在的位置。

## 如何获取

请从该工具的原始发布来源下载 `codebase-memory-mcp.exe`，并放置到本目录：

```
codebase-memory/codebase-memory-mcp/codebase-memory-mcp.exe
```

## 占位文件说明

- `codebase-memory-mcp.exe.请自行下载真实文件.txt`：0 字节占位文件，文件名即提示——真实可执行文件需自行下载，**切勿将其当作可用程序**运行。
- 仓库通过 `.gitignore` 忽略 `codebase-memory/` 整体；本次仅以显式强制添加纳入了目录骨架、文档与脚本。真实的 `codebase-memory-mcp.exe` 二进制与运行时 `data/` 内容不入库。
