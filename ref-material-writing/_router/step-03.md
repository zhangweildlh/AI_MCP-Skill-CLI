## [执行]

### 3.1 加载分析卡片
从输出目录读取所有 `_card_[资料ID].json`，按资料 ID 建立索引。

### 3.2 识别直接关联关系（6 类）
| 关系 | 定义 |
|------|------|
| 引用关系 | A 明确提及 / 引用 B 的内容或数据 |
| 佐证关系 | A 的论点可被 B 的论据支撑 |
| 互补关系 | A、B 分别覆盖同一主题不同维度 |
| 冲突关系 | A、B 对同一事实 / 数据矛盾表述 |
| 反驳关系 | A 直接反驳 / 质疑 B 的观点 |
| 时间演进 | B 是对 A 的更新且时间晚于 A |
- 每条关系注明证据来源。

### 3.3 推导多跳关联
- 最大跳数：默认 3 跳。
- 输出格式：来源、目标、跳数、路径、综合关系。

### 3.4 构建关系图与信息溯源表
- 关系图：Mermaid 格式，保存为 `_relation_graph.md`。
- 关键信息溯源表：每条关键事实对应来源资料 ID、出处、佐证资料。

### 3.5 关联分析结果输出
保存为 `_交叉引用结果.json` 与 `_relation_graph.md`。
