# 知识库：禁止项清单

> **【唯一权威来源】**：本文件是禁止项清单的唯一权威来源。步骤7合规自检时，必须加载本文件并逐项对照检查。

---

## 禁止项清单

| ❌ 禁止 | ✅ 应该 |
|---------|---------|
| 未读完参考资料就开始写作 | 完整阅读每一份资料后再动笔 |
| 编造参考资料中不存在的数据或事实 | 标注缺口并搜索补全，或明确告知用户 |
| 跳过跨资料分析，孤立使用每份资料 | 分析多跳转移关系，整合所有资料形成关系图谱 |
| 搜索结果仅看第一条就采用 | 至少 2 个独立来源交叉验证后再使用 |
| 擅自大幅修改提纲而不告知用户 | 先建议→确认→再修改，调整内容公示 |
| 偏离用户需求自行发挥 | 严格对齐用户全部写作需求 |
| 对参考资料内容进行歪曲或过度解读 | 忠实于原文，推断须显式标注『[推断]』并附原文依据 |
| 使用「据悉」「有报道称」等模糊表述 | 明确标注具体来源或说明信息不确定性程度 |
| 在无法找到可靠来源时强行补全内容 | 标注「[数据待核实]」并告知用户 |
| 发现资料间矛盾时偏袒一方 | 明确呈现矛盾双方及各自依据 |
| 脱离参考资料空谈政治站位或宏观形势 | 每个战略判断均有参考资料或验证数据作为支撑 |
| 建议过于空泛、缺乏可操作性 | 建议必须具体、可行，有实施主体、路径和条件分析 |
| 项目建议书变成空洞的技术规格书或宣传册 | 将技术优势翻译为甲方语言，讲清商业价值和落地实效 |
| 使用 OfficeCLI 时主观猜测属性名或命令语法 | 执行 `officecli help <cmd>` 确认后再操作 |
| **一次性拉取超长 Office 文件全文** | **严格按分段读取策略逐段读取** |
| **将 docx 的 `--start/--end` 段落参数用于 xlsx 或 pptx** | **按文件类型选择正确的分片参数** |
| **单批次写入超过 12 个操作** | **每批次 ≤12 操作，长文件拆分多批次** |
| **单段落文本超过 3000 字符而不拆分** | **超过阈值必须拆分为多条连续段落** |
| **在驻留打开期间运行 validate 或任何文档结构校验** | **先 close 再 validate；所有校验在 close 之后的独立 shell_exec 中执行** |
| **写入阶段使用位序路径作为主要寻址方式** | **优先使用稳定 ID（@paraId/@id）寻址** |
| **批次写入失败后继续执行下一批次** | **批次失败立即 close；累计≥2次降级到Markdown输出** |
| **分段读取时跳过大纲索引映射表的持久化** | **第一步 view outline 必须产出并持久化索引映射表** |
| **检索阶段 CSS query 返回空结果后继续执行写入** | **空结果→终止检索分支并告知用户** |
| **将 PDF 参考资料通过 OfficeCLI 分片读取** | **PDF 通过系统原生能力处理** |
| **跨 shell_exec 分步执行 create/open/add/close** | **所有写入操作合并在一个 shell_exec 中，用 ; 连接** |
| **create 命令不带 --force** | **create 必须带 --force** |
| **create 后显式 open（无必要且可能引入延迟）** | **create 后直接 add，跳过 open** |
| **单次 shell_exec 命令字符串超过 7000 字符** | **超过 7000 字符时按 ≤12 条 add 拆分为多个自包含批次** |
| **写入后仅依赖 exitCode 判断成败** | **必须执行 4 条错误检测规则（stderr Error 检查、stdout 段落计数、close 确认、超时检测）** |
| 在 .docx 文件中存在高相似段落却未标记为蓝色（视觉提醒） | 必须执行「步骤8：段落相似度检测与标记」，并在写入时设置蓝色字体 |
| **将"意尽言止"执行为"读者基本能懂就停笔"** | **完成多维度充分论证后杜绝无效赘述，达到目标受众可被充分说服的论证深度** |
| **使用单句带过式论点（仅一句话抛出观点后直接跳转）** | **长文关键论点采用"观点+政策支撑+数据佐证+落地解读"四段式结构** |
| **开篇铺垫的核心政策依据在后续章节中无任何呼应引用** | **每项核心政策至少在后续两个关键章节中精准引用，形成完整证据链闭环** |
| **正文撰写阶段因预判OfficeCLI分片约束而压缩段落长度** | **步骤6充分展开论证，步骤9仅做技术性段落拆分和写入** |
| **忽视联网搜索素材，仅依赖本地参考资料写作** | **每章至少引用3处搜索来源，与参考资料同等重视** |
