# 自检标准档 D：检索来源产出物

> 适用：step-05 `_网络搜索素材.md`、step-02 来源登记、其他外部检索汇总。
> 调用位置：step-05 [验证] 段；RESUME-CHECK 据本档判定关键词级 half / missing（设计点 4）。

## 必过项

1. **存在性**：`FILE_STAT` 确认文件存在。
2. **非空阈值初筛**：字节数 < 1KB 视为明显损坏。
3. **轻签名**：字节数 + 条目数 vs [产出] 预期。
4. **结构完整性**：
   - 每关键词双引擎段落齐全，对齐「阶段检查点」`Kx-AnySearch done` / `Kx-Firecrawl done` 计数（缺失任一侧 → half）；
   - 来源条数 ≥ 参数 `min_independent_sources_per_claim`（默认 2）；每论点 ≥ 2 独立来源；
   - 含 `[资料X]` / `[搜索X]` 溯源标记。
5. **模型输出截断（B 类）**：某关键词段落突兀截止 → 判 ❌（该关键词 half）。

## 回填 / 回退（设计点 6）

- 情形A 回填（如实际条目多于登记）；
- 情形B / C 回退（补跑缺失引擎 / 关键词，回退到 step-05 对应子阶段）。

## 完整性 vs 正确性

本档验 integrity（来源齐全 / 结构完整）；来源内容正确性（如事实准确度）由 step-07 覆盖。

## 与 §14 衔接

- 本档验 **integrity**（来源齐全 / 结构完整）；来源内容正确性（事实准确度）由 step-07 覆盖（设计点 8B）。
- step-05 自检通过 → 向状态文件 §14 写入"✅通过 + 轻签名（字节数,条目数）+ 登记对象=`[输出目录]/_网络搜索素材.md` + 子阶段=关键词级（如 K3-Firecrawl done）+ 自检时刻"；失败回退补跑缺失引擎 / 关键词后重检（设计点 5/6）。
