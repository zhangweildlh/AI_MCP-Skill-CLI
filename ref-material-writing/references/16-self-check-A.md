# 自检标准档 A：文本 / Markdown 产出物

> 适用：step-04 `_提纲.md`、step-06 `_正文过程稿.md`、step-08 `_相似段落标记.md`、step-03 衍生文本、其他 Markdown 中间产物。
> 调用位置：各 step [验证] 段引用本档必过项；RESUME-CHECK 据本档判定 half / missing（设计点 4）。

## 必过项（全部满足方登记 ✅通过）

1. **存在性**：`FILE_STAT` 确认文件存在（或映射表等价 `Test-Path` / `test -f`）。
2. **非空阈值初筛**（设计点 7）：字节数 < 2KB 视为"明显损坏"，直接判 ❌（最廉价初筛，非唯一判据）。
3. **轻签名**：`FILE_STAT` 取字节数 + 行数（或段落数），与 [产出] 声明预期值比对；偏差 > 10% 触发复核。
4. **结构完整性**：
   - 提纲（`_提纲.md`）：一级 / 二级标题数 ≥ 提纲条目数下限；末级标题后应有正文段落（非空白收尾）。
   - 正文（`_正文过程稿.md`）：章节数 ≥ 提纲章节数；每章段落数 ≥ 1；文档末尾为完整句 / 段落（非突兀截断特征，如末行缺句号且无续写标记）。
   - 标记（`_相似段落标记.md`）：标记条数 ≥ 预期（step-08 判定数）；每条含"段落位置 + 相似对象"两字段。
5. **模型输出截断特征（B 类）**：末尾出现"…（待续）""（未完）"或末段落明显被截断（缺闭合标点且无后续文件）→ 判 ❌。

## 回填 / 回退（设计点 6）

- **情形A（登记残缺但实际完整）**：下游读回发现实际字节 / 行数 > 登记声明 → 以实际值**回填** §14 登记，不重做。
- **情形B（登记完整 / 残缺但实际残缺 / 缺失）**：实际不完整 → **回退重做**本步 [执行]→[产出]→[验证]，重写登记。
- **情形C（本步不需功能性回读）**：轻检发现残缺 → 同情形B 回退。

## 自检仅验完整性（设计点 8B）

本档验 **integrity（存在 / 非空 / 结构完整）**；**正确性（事实 / 幻觉 / 溯源）** 由 step-07 / step-10 负责，本档不覆盖。
