# 文风要求、语气规范与标题规范

## 文风要求（核心约束，严格遵守）

### 站位与格局
立足国家和省市战略全局和宏观政策导向，把握国内外政治经济发展大势，体现战略思维和全局视角。与此同时，每一个战略判断都需有具体数据、案例或政策文件作为支撑，每一项建议都需有明确的实施路径和可操作性，避免"有高度无抓手""有方向无路径"的弊病。

### 平实庄重
采用正式、严谨、平实、沉稳的文风，不使用比喻、拟人、夸张等修辞手法，不追求文采华丽。

### 客观中性
不出现第一人称主观判断（如「我认为」「我觉得」），用事实和数据说话。

### 逻辑严密
段落之间必须有明确的递进、并列或因果关系，使用「一是…二是…」「一方面…另一方面…」等结构词衔接。必须层次清晰，前后呼应，论证充分，论据可靠。

### 拒绝口语化
不得出现「咱们」「大伙儿」「说白了」「基本上可以说」等口语或模糊表达。

### 拒绝网络用语
不得出现「赋能」「抓手」「闭环」「颗粒度」「底层逻辑」等过度流行的管理咨询用语。

### 拒绝空话套话
不写「在…领导下」「在…指导下」「高度重视」「切实加强」等无信息量的程式化表述，除非原文引用政策文件。

### 建议必须具体、可行
避免空泛的口号式表述。

### 精炼简洁
做到「意尽言止」，不堆砌辞藻，不冗长啰嗦。**默认**每句话不超过 40 字，能用一个词不用两个词，能一句话说清不分两句。

**【「意尽言止」约束的边界定义】**：
- 本约束的正确定义为：**在完成多维度充分论证的前提下杜绝无效赘述、空话套话和重复冗余表述**。
- **禁止误解为**：目标受众基本理解语义即可停止论证。
- **正确执行标准**：必须达到目标受众可被充分说服的论证深度，不可仅满足于基础语义读懂。
- **判断标准**：若删去某句话后，论证链条出现断裂、论据出现缺失、推导出现跳跃，则该句话属于必要内容，不得删除。

### 论述密度规则（与字数目标联动）

| 字数区间 | 论述密度要求 |
|----------|-------------|
| **<3000字（短篇）** | 严格遵循"每句≤40字""意尽言止"；每个二级标题下至少1个独立论证段落 |
| **3000-5000字（中篇）** | 每个二级标题下至少2个独立论证段落；每个关键论点至少引用1处参考资料或搜索数据 |
| **≥5000字（长篇）** | 单句40字限制放宽至70字（复合句）；全文平均句长仍≤40字；每个二级标题下2-3个论证段落；每个关键论点至少引用2处来源；同一观点至少2个维度展开 |

### 核心论点论证结构规范

| 文稿类型 | 论证结构 |
|----------|---------|
| **短文稿（<3000字）** | 关键论点至少包含"观点 + 数据/政策支撑"两段式 |
| **中文稿（3000-5000字）** | 关键论点至少包含"观点 + 政策/数据支撑 + 解读"三段式 |
| **长文稿（≥5000字）** | 观点陈述 + 政策/理论支撑 + 数据/案例佐证 + 落地解读/价值推导（四段式） |

**禁止使用单句带过式论点表述**——即不得仅用一句话提出观点后直接跳转到下一个论点，中间无任何支撑和解读。

### 项目建议书和合作建议书专项：换位思考
在商务说服型文稿中，始终以甲方（地方政府/业主）的发展需求为第一视角，将"我们想做什么"转化为"我们能为您带来什么价值"。充分展现项目的政治经济价值、社会民生效益和产业带动效应。

## 语气规范（核心约束，严格遵守）

| 语气原则 | 具体要求 |
|----------|----------|
| **陈述语气为主** | 调研报告、情况分析等以陈述事实和结论为主，不设问、不反问 |
| **建议语气适度** | 项目建议书中使用「建议」「宜」「可」「应」等节制性措辞，不使用「必须」「务必」（除非引用上级要求） |
| **战略判断有据可依** | 使用"从国家战略布局来看"等引出高站位分析，每句战略判断附具体事实或数据支撑 |
| **结论明确但不武断** | 使用「数据显示」「调研表明」「从…来看」等引出结论 |
| **不讨好、不煽动** | 不写「令人振奋」「值得关注」等价值判断短语 |

### 项目建议书/合作建议书专项：商务说服语气
语气从"客观陈述"调整为"专业说服"。使用"分析表明……因此建议贵方……"的论证闭环，用强有力的逻辑推导和效益预测，增强文稿的感染力与说服力，但始终保持专业底线。

## 标题规范

- **结构统一**：同一层级的标题结构一致，字数相近，句式工整对仗。要么全部「名词性短语」，要么全部「动词性短语」，要么全部「动宾结构」或「主谓结构」。
- **字数对仗**：同一层级标题字数尽量相近，通常不超过 15 个汉字。
- **不设问**：标题使用陈述式，不使用问句。
- **层级分明**：
  - 一级标题（如「一、二、…」）：概括性最强，6-12 个汉字。
  - 二级标题（如「（一）（二）…」）：承接、呼应一级，8-15 个汉字。
  - 三级标题（如「1. 2. …」）：具体指向，不超过 12 个汉字。
