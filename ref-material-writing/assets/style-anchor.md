# 风格锚点（style-anchor）

> **用途**：步骤6 每章动笔前（R4 反稀释加载）必须重载本文件，作为文风 / 语气 / 标题的"防遗忘锚点"。
> 权威完整规范见 `references/01-writing-standards.md`；本文件为精简速记，冲突以 01 为准。

---

## 一、文风（核心约束）
- **平实庄重**：正式、严谨、平实、沉稳；不用比喻 / 拟人 / 夸张 / 华丽辞藻。
- **客观中性**：不出现「我认为 / 我觉得」等第一人称主观判断；用事实和数据说话。
- **逻辑严密**：段落间须递进 / 并列 / 因果；用「一是…二是…」「一方面…另一方面…」衔接。
- **拒绝口语化**：禁「咱们 / 大伙儿 / 说白了 / 基本上可以说」。
- **拒绝网络用语**：禁「赋能 / 抓手 / 闭环 / 颗粒度 / 底层逻辑」。
- **拒绝空话套话**：禁无信息量的「在…领导下 / 高度重视 / 切实加强」（除非原文引用政策）。
- **精炼简洁**：默认每句 ≤ 40 字；长篇（≥5000字）单句放宽至 70 字但平均句长仍 ≤ 40 字。「意尽言止」= 完成多维论证后杜绝无效赘述，非"读者能懂就停笔"。
- **论述密度**：中篇每二级标题 ≥ 2 论证段、每关键论点 ≥ 1 引用；长篇四段式（观点+政策/理论+数据/案例+落地解读），每关键论点 ≥ 2 来源。

## 二、语气（核心约束）
- 陈述语气为主，不设问 / 不反问。
- 建议语气适度：用「建议 / 宜 / 可 / 应」，禁「必须 / 务必」（除非引用上级要求）。
- 战略判断须附具体事实 / 数据支撑。
- 结论明确但不武断：用「数据显示 / 调研表明 / 从…来看」。
- 不讨好、不煽动：禁「令人振奋 / 值得关注」。

## 三、标题规范
- **结构统一**：同层级要么全名词性、要么全动宾 / 主谓，句式工整对仗。
- **字数对仗**：同层级字数相近，通常 ≤ 15 汉字。
- **不设问**：陈述式，禁问句。
- **层级分明**：一级 6–12 字、二级 8–15 字、三级 ≤ 12 字。

## 四、风格一致性自检（写入每章上下文摘要时勾选）
- [ ] 本章文风是否符合"平实庄重 / 客观中性 / 精炼"？
- [ ] 是否出现口语 / 网络用语 / 空话套话？（应无）
- [ ] 标题是否同层级结构统一、字数对仗、无设问？
- [ ] 平均句长是否 ≤ 40 字（长篇放宽单句但平均仍 ≤ 40）？
- [ ] 每关键论点是否达到对应论述密度与引用数要求？
- [ ] 开篇政策依据是否已在后续章节呼应引用？
