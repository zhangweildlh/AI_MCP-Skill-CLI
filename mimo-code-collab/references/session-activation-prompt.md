# 首条注入提示词（提醒主 Agent 在主任务前判断是否激活本 Skill）

## 用途
在**对话会话的第一条消息**中注入以下提示词（或将其写入主 Agent 的常驻系统提示 / 记忆），用于在"整个对话 / 主任务开始之前"提醒主 Agent：先判断本次任务是否涉及 `mimo.code` 协同，若涉及则先加载 `mimo-code-collab` 技能再开工。

## 精简提示词（直接复制使用）
> 在动手做任何事之前，先判断：本次对话 / 主任务是否涉及「mimo.code（小米 MiMo 代码智能体）」的协同——包括代码编写 / 修改 / 审核、技术方案讨论、GitHub 内容生成与审阅，或任何"主Agent 出题 / 审查 + mimo 实现 / 修订"的分工场景。若涉及，请先加载 `mimo-code-collab` 技能（或显式调用 `/mimo-code-collab`），并按其中的"强制前置分析约束"在每一步开工前判定适用场景与范式，再正式开展；若不涉及，正常处理即可。

## 用法说明
- **会话首条注入**：把上方"精简提示词"作为本轮对话的第一条用户消息发送，主 Agent 会在开工前完成判断。
- **常驻增强（双保险）**：将其写入常驻记忆 / 系统提示，等价于"涉及 mimo.code 的协同任务，先加载 mimo-code-collab 技能"，可提升自动加载覆盖率（本技能本身不依赖固定激活词，靠语义匹配）。
- **与本技能内部闸门的关系**：本提示词解决"是否激活 Skill"（会话级闸门）；Skill 内部的"强制前置分析约束（第 1.5 节）"解决"激活后每步开工前是否判定了场景与范式"（子任务级闸门）。两者是前后两道独立闸门。
